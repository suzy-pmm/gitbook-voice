Push to LinkedIn

To publish directly from GitBook Voice, connect via LinkedIn's OAuth API. Requires a LinkedIn Developer App with w_member_social permission.

Once connected, posts are pushed to each person's LinkedIn for a final one-click review before going live.

Setup steps
1. Create a LinkedIn Developer App at developer.linkedin.com
2. Request w_member_social + r_liteprofile scopes
3. Add your OAuth callback URL
4. Paste your Client ID and Secret below
